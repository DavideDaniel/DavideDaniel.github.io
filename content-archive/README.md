# content-archive

Preserved content that is **no longer deployed** to the live site.

## musings/

The retired `/musings` AI-engineering content hub (4 articles + manifest). The
route, page component, and styles were removed from the site for SEO reasons
(the section was experimental and de-indexed). These markdown files are kept
here so the writing isn't lost — they live in the repo and git history but are
**not** built into `dist/` and are **not** crawlable.

To revive any of this, move the files back under `public/content/` and restore a
route in `src/App.jsx`.
